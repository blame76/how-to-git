# Gestaltung: das Lernjournal

Die Oberfläche ist **ein Leseraum**, kein Schulungsdashboard.

## Leitlinien

1. **Inhalt führt.** Jede Bildschirmfläche muss eine Entscheidung erleichtern oder Wissen vermitteln. Module stehen in einem nummerierten Inhaltsverzeichnis statt in austauschbaren Karten.
2. **Ein klares Raster, ein bewusster Bruch.** Eine ruhige, gut lesbare Satzspalte trifft auf eine große redaktionelle Überschrift oder eine marginale Randnotiz. Keine zufälligen Unregelmäßigkeiten.
3. **Typografie vor Dekoration.** Eine systemeigene Sans für Bedienung und Fließtext, eine Serif für Aussagen und Kapitel. Keine externen Font-Requests.
4. **Signal statt Konfetti.** Dunkles Graphit, warmes Papier, gedämpfte Sekundärfarbe. Ziegelrot kennzeichnet wenige wichtige Stellen; nicht jeder Klick braucht ein Ausrufezeichen.
5. **Lernkontrollen gehören zum Text.** Auswahlmöglichkeiten sind lesbare Zeilen, keine Spielshow. Feedback erklärt Ursachen, nicht nur Richtig/Falsch.
6. **Mobile ist kein Restformat.** Keine horizontale Scrollpflicht bei 320 px. Auf kleinen Displays wird die Randspalte zum kompakten Fortschritt über dem Kapitel.
7. **Barrierefreiheit ist Bestandteil der Gestaltung.** Hoher Kontrast, sichtbarer Tastaturfokus, echte Formulare, sinnvolle Überschriften, keine Information ausschließlich über Farbe.
8. **Substanz vor Effekten.** Keine Illustrationen ohne didaktischen Zweck. Keine unnötigen Animationen, keine Benutzerkonten, keine Tracker.

## Review-Fragen

- Würde die Seite ohne die Randnotiz oder den dekorativen Marker klar funktionieren?
- Kann jemand nach einer Minute erkennen, was gelesen und als Nächstes getan werden soll?
- Wirkt die Oberfläche wie eine ernsthafte Publikation statt ein Dashboard?
- Sind die einzelnen Antworten auch bei ausgeschalteter Farbwahrnehmung unterscheidbar?
- Funktionieren Bedienung und Lesefluss mit Tastatur, Screenreader und auf einem Telefon?
- Haben die typografischen Brüche eine Absicht oder sehen sie nur ungewöhnlich aus?

## Bewusste Grenzen

Die erste Überarbeitung baut einen Gestaltungsrahmen. Sie ist **keine visuell abgenommene Veröffentlichung**: responsive Abstände, Tastaturbedienung, Lesbarkeit und Kontrast müssen vor der Freigabe im Browser geprüft werden.
